# Devidas Zende — Cybersecurity Portfolio

A responsive static portfolio built with HTML, CSS, and vanilla JavaScript. It is designed as a polished, editorial-style personal portfolio with cybersecurity branding, project showcases, service descriptions, about/skills sections, journal links, and a contact form that opens the visitor's email app.

## Files

- `index.html` — site content and structure
- `style.css` — visual design and responsive layouts
- `script.js` — mobile navigation, current year, and email draft form
