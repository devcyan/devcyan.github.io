# Devidas Zende — Cybersecurity Portfolio

A responsive static portfolio built with HTML, CSS, and vanilla JavaScript. It is designed as a polished, editorial-style personal portfolio with cybersecurity branding, project showcases, service descriptions, about/skills sections, journal links, and a contact form that opens the visitor's email app.

## Files

- `index.html` — site content and structure
- `style.css` — visual design and responsive layouts
- `script.js` — mobile navigation, current year, and email draft form

## Before publishing

1. In `script.js`, replace `YOUR_EMAIL_HERE@example.com` with the email address you want to publish.
2. Review every project description and link. Update project links as repositories become available.
3. Add a resume PDF as `resume.pdf` if you decide to include one; the current design does not link to a fake or missing file.
4. Only add client logos, testimonials, client counts, certifications, or performance statistics if they are genuine and you have permission to publish them.
5. Check the site on mobile and desktop before sharing it publicly.

## Run locally

Open `index.html` in a browser, or use VS Code's Live Server extension.

## Deploy free with GitHub Pages

1. Create a public repository named `devcyan.github.io`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/(root)`, then save.
5. After deployment, visit `https://devcyan.github.io`.

## Contact form note

The form uses a `mailto:` link. It does not send messages through a server and does not store form submissions. A backend or form service would be needed for an embedded submission experience.

## Ethical security note

Security review services should only be offered and performed with explicit authorization and an agreed scope. Keep descriptions aligned with actual skills and experience; update the service list as your capability grows.
